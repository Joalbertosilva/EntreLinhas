# Histórico — 2026-08-25

## Resumo

Refinamento da ordem de entrega e decisões de design antes de iniciar código.

## Decisões

1. **Gerenciador web é essencial** — RF001/RF002: sem cadastro público; admin cadastra todos os usuários
2. **Ordem na web:** gerenciador (admin + professor) **antes** da área aluno
3. **Backend antes do gerenciador** — gerenciador precisa de auth, profiles, Edge Function create-user
4. **Gerenciador só web** — professor/admin sem app mobile no MVP
5. **Paleta provisória:** azul `#1B4F8A`, branco, amarelo `#C99700` — tons acessíveis (WCAG AA)
6. Cores finais após conversa com faculdade/cliente → `docs/design-system.md`

## Dúvidas esclarecidas

- Não estilizar gerenciador antes do backend (dependência técnica)
- Gerenciador vem logo após backend mínimo — prioridade máxima na Fase 2 Web
